# ☕ Aura Brew — Responsive Product Landing Page

A modern, responsive coffee subscription landing page built
using HTML5 and CSS3.

Aura Brew is a coffee brand concept designed to showcase
premium coffee subscriptions through a clean layout, warm
colors, and a user-friendly interface.

## 🌟 Project Overview

Aura Brew presents a coffee subscription service with
information about the brand, its coffee experience, product
benefits, subscription plans, and newsletter signup.

The design combines dark coffee-inspired sections with warm
cream backgrounds and golden accents to create a consistent
visual identity.

## ✨ Features

- Responsive product landing page
- Coffee-inspired visual design
- Hero section with a call-to-action button
- Brand experience section
- Product benefit cards
- Three coffee subscription plans
- Newsletter signup section
- Navigation links to key sections
- Clean typography and structured layouts

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎨 Design Highlights

- Warm, coffee-inspired color palette
- Dark brown and cream section backgrounds
- Golden accent colors
- Card-based subscription plan layout
- Clear headings and call-to-action buttons
- Organized page sections
